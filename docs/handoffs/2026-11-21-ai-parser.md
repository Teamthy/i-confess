# Handoff — Claude-backed session builder parser

**Date:** 2026-11-21 · **Branch:** `claude/dreamy-faraday-7th0my` · **Commits:** `325cac1` (parser), plus the handoff-process commit · **PR:** none opened

## Goal

1. Audit what in the project is not properly built.
2. Fix the AI parser behind `POST /ai/parse` and `/v1/ai/parse`.
3. Make a handoff mandatory at the end of every session.

## What changed

**AI parser (`325cac1`)**
- `AI_PROVIDER=anthropic` now calls Claude through the official Go SDK
  (`github.com/anthropics/anthropic-sdk-go/v2` v2.13.0). Before, it silently
  ran the keyword parser. Code: `server/internal/ai/llm_adapter.go`.
- Structured output limits Claude to the slugs of the published categories,
  and the server re-checks them. It returns up to 3 categories plus an
  optional length. Only the utterance is sent, and the voice always comes from
  the caller. Settings: model `claude-opus-5-5` (override with `AI_MODEL`),
  effort `low`, 20 s timeout, 1 retry, server-side refusal fallbacks.
- If the call errors, times out, is declined or returns nothing usable, the
  keyword parser answers and the response says `"parser": "keyword-fallback"`.
- Startup now fails on an unknown `AI_PROVIDER` (including the unimplemented
  `openai`) and on `anthropic` without `ANTHROPIC_API_KEY`
  (`server/internal/config/config.go`, `server/cmd/server/main.go`).
- **Bug fixed:** `engine_request` carried slugs, but the engine selects by
  category database ID, so it never matched content. The handler now reads
  categories from the database and maps slugs to IDs
  (`server/internal/api/handlers_ai.go`).
- **Bug fixed:** the keyword parser returned `sleep` and `future`, which are
  not categories. It now maps them to `rest` and `hope`, returns only published
  categories, and is deterministic (`server/internal/ai/builder.go`).
- The new settings are documented in `server/.env.example`.

**Handoff process (this commit)**
- `CLAUDE.md` makes a handoff mandatory; the template is `docs/handoffs/TEMPLATE.md`.
- A Stop hook (`.claude/settings.json` → `.claude/hooks/require-handoff.sh`)
  blocks finishing while the branch has commits newer than its latest handoff.
